# 录像回放与弹幕

在 SwiftPeek 里观看斗鱼主播的直播录像（`v.douyu.com/show/…`），弹幕按当时的时间轴重新飞过画面。

## 入口

- 直播间顶部的“录像”按钮：列出这位主播的全部录像，按场次分组。
  iPhone 上主播未开播时，画面中央还会显示“看录像”。
- 关注列表：Mac 右键关注卡片或历史卡片选“查看录像”；iPhone 长按或左滑关注行。
- 粘贴录像链接：Mac 主窗口的搜索框、iPhone 的搜索页都可以直接粘贴
  `https://v.douyu.com/show/<编号>`，链接里的 `t=` 起播秒数会被保留。

## 播放

- 录像是标准 HLS（H.264 / AAC），交给系统 AVPlayer：拖动、倍速（0.5×–2×）、缓冲与画中画都由系统完成。
- 清晰度一般有高清（720p）、超清、1080P60、1440P60 四档，默认画质跟随“设置 → 画质偏好”。
- 一场直播会被斗鱼切成约 2 小时一段；播完自动接下一段，也可以在“选集”里手动切换。
- 每段录像记住看到哪里（最近 300 段，存在本机），再次打开从上次位置继续；看完或只看了开头的不记。
- 播放地址带签名，约 2 小时失效。播放出错时自动重新取地址并从原位置继续，连续失败两次后交给用户重试。

## 弹幕

- 弹幕按 500 条一个时间窗口分批拉取，只在当前进度前约 90 秒预取，不一次性下载全部。
- 拖动进度时清屏，从新位置继续；拖回已加载的范围不会重复请求。
- 暂停时屏上弹幕冻结，继续播放时接着飞。
- 侧栏的弹幕列表显示当前进度之前的弹幕和它们出现的时间，点一条就跳到那一刻。
- 字号、速度、透明度、显示区域和屏蔽词沿用直播弹幕设置。
- 进度条上方的热度曲线由后台扫一遍弹幕统计得到；弹幕超过约 2 万条时只统计前面一部分。

## AI 章节

斗鱼为部分录像生成了 AI 章节（标题、摘要、分类）。章节标在进度条上，侧栏可点击跳转。
章节按整场直播编排，跨段的章节在后一段从开头显示，并标注“接上段”。没有章节的录像不显示这部分。

## 接口

全部接口无需登录、不使用 Cookie。

| 用途 | 接口 |
| --- | --- |
| 录像信息、签名脚本 | 录像页 HTML 内嵌的 `window.$DATA` 与内联 `ub98484234` 脚本 |
| 播放地址 | `POST /wgapi/vodnc/front/stream/getStreamUrlWeb`（签名对象是录像的 `point_id`） |
| 弹幕 | `GET /wgapi/vod/center/getBarrageList?vid=&start_time=&end_time=-1` |
| AI 章节 | `GET /wgapi/vod/center/aivideo/mainV1?vid=` |
| 主播录像列表 | `betard/<房间号>` 取 `up_id`，再调 `authorShowVideoList` |
| 同场分段 | `GET /wgapi/vod/center/getShowReplayList?vid=&up_id=` |

这些是斗鱼网页内部接口，没有公开文档，网页改版后可能失效。签名脚本的版本号按天变化，每次取流都重新抓页面。
只做在线播放，不提供下载。

## 验证边界

- 核心库新增 14 项测试：链接识别、页面解析、真实签名脚本对录像编号签名、清晰度、弹幕窗口、章节归属、列表与分段。
- `macos_native/Checks/check-replay.sh` 用假接口验证弹幕投放顺序、屏蔽词、拖动清屏与重新加载、预取、
  暂停不投放、观看进度保存与恢复、热度曲线归一化。
- `swift run douyu-probe replay <房间号或录像链接>` 对真实接口跑通了列表、信息、四档地址、弹幕窗口和章节，
  只打印地址前缀。
- macOS 与 iOS 模拟器 Debug 构建通过。按既定约定未启动 App 窗口、未进行 GUI 试播；
  实际画面、画中画、全屏旋转与后台音频需要在设备上确认。
