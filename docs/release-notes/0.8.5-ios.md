# SwiftPeek 0.8.5 — iOS 界面刷新

版本 **0.8.5 (19)**，适用于 iPhone、iPhone Duo 和 iPad。

## 更干净的卡片

- 直播间卡片去掉封面上的「直播中」和热度徽标，只有轮播房间在封面角标出「轮播」。
- 标题收为一行，第二行显示主播与热度，每张卡高度一致。
- 封面加载改为浅底占位并淡入，卡片按下有轻微回弹。

## 关注与主播

- 关注标签和按钮统一改为心形。播放页里「关注」移到主播信息行：未关注时为品牌色按钮，关注后变为普通样式。
- 关注列表中正在直播的主播排在最前，头像外圈带橙色细环；加载前显示名字首字。
- 空状态补充引导文字；没有关注时只保留「导入」，不再显示无内容的「分享关注」。

## 分类、搜索与「我的」

- 分类页改为顶部分区滑块加当前分区的图标网格，常用分区一屏可见；选中项为可滑动的玻璃块。
- 分类图标不再套卡片；深色模式下使用浅色底板，深色图标也能看清。
- 搜索页提示可以输入主播昵称、房间号或直接粘贴直播间 / 录像链接。
- 「我的」页显示版本号，列表图标改为中性灰，品牌橙只用于选中与直播状态。

## 播放、录像与多画面

- 播放页标题在上，主播、热度、已播时长与关注在同一行。
- 录像页只把当前章节标为品牌色，其余时间戳对齐成一列。
- 多画面的操作移到系统底部工具栏；每一路改为浮在画面底部的玻璃按钮，不再占一整条实底栏，四路同看时每路画面更大。
- 弹幕关闭时加删除线，不只靠透明度区分开关。

## 下载与安装

- **iOS / iPadOS 26+、arm64** 设备包，不适用于模拟器。
- `SwiftPeek-0.8.5-iOS-unsigned.ipa` 是**无签名 IPA**，不含维护者个人签名身份或 provisioning profile。需要使用自己的有效签名身份重签后侧载，不能直接安装。
- 同时提供匹配本标签的 `SwiftPeek-0.8.5-source.zip` 和 `SHA256SUMS.txt`；请核对下载文件的 SHA-256。
