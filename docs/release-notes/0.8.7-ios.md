# SwiftPeek 0.8.7 — 播放稳定性与体验修复

版本 **0.8.7 (21)**，适用于 iPhone、iPhone Duo 和 iPad。

iOS 上一版是 0.8.5。本版同时包含 [macOS 0.8.6](0.8.6-macos.md) 已发布的共享改进：自适应缓冲、断网等待与网络恢复续播、弱网自动降一档清晰度、线路并行解析与签名缓存，以及直播 / 轮播 / 未开播 / 待确认四态直播状态。以下是 0.8.7 新增的修复。

## 播放与切页

- 同一时间只有一个页面在播：在一个 Tab 里开着直播间，再到另一个 Tab 打开直播或录像时，前一个自动暂停；切回原页面时从暂停处继续，不重新加载。退出多画面时，也不会把隐藏 Tab 里的房间重新拉起来。
- 从直播间进入「录像」再返回后，弹幕继续更新，并重新获取直播地址，不再沿用可能已过期的旧地址。
- 直播页被深链直接替换时，旧房间会停止拉流和弹幕，不再在后台继续出声。
- 离开录像页时结束画中画，并保存进度与音量；回到录像页从保存的位置继续。
- 在直播间看了较长时间再返回推荐 / 分类列表时，列表保持原来的位置，不再跳回第一页；只在切回应用或下拉时刷新。

## 多画面

- 弱网自动降低清晰度后，不会在约 1 秒后又被自动调回原画质，避免反复重连和黑屏闪烁。
- VoiceOver 区分「主画面」与「副画面」。

## 直播播放

- 修正缓冲时长计算，避免起播与卡顿后续播的门槛失效。
- 后台换流失败后持续退避重试，接口短暂抖动不再导致约 5 分钟后断流。
- 单个异常数据包不再结束整场播放；声音不再长期领先画面；视频时间戳倒退时重新对齐，不再冻结画面。
- 播放循环减少空转唤醒，多画面同时播放时更省电。

## 画中画

- 小窗弹幕在重连、暂停后继续时，不再冒出一批旧弹幕。
- 无缝换流时小窗画面和弹幕不再卡住；解码器重置后等关键帧再显示，避免花屏。
- 录像小窗的播放 / 暂停按钮状态及时更新；弹幕隐藏时不再合成画面，更省电。
- 暂停 / 继续时小窗弹幕不再闪烁；修改无关设置时小窗不再切换内容源。

## 弹幕

- 断网后弹幕不再在约 25 秒后永久断开：不限次数重连，网络恢复时立即重连；长时间收不到数据会判定连接失效并重连。
- 弹幕恢复不再清掉「取流失败」之类的提示。
- 全屏时弹幕列表不再在后台滚动。

## 关注、链接与数据

- 用别名或短房间号进入直播间时，关注按钮显示正确，不会把已有关注误取消。
- 链接解析只接受明确格式（`simplelive://room/房间号`、`douyu:房间号`、斗鱼网页链接），不再把链接里的所有数字拼成房间号。
- 关注状态查询最多同时 5 个；状态未知的主播单独显示为「状态未知」；状态无变化时不重写关注文件。
- 后台刷新列表失败时保留已加载的页码；轮播房间的状态确认在快速滚动后也能完成。
- 关注或历史文件读取失败时先备份为 `*.corrupt-<时间>.json`，跳过损坏条目、保留完好条目，不再被空列表覆盖。
- 封面与头像图片增加内存缓存并按显示尺寸缩略解码，滚动更顺。

## 下载与安装

- **iOS / iPadOS 26+、arm64** 设备包，不适用于模拟器。
- `SwiftPeek-0.8.7-iOS-unsigned.ipa` 是**无签名 IPA**，不含维护者个人签名身份或 provisioning profile。需要使用自己的有效签名身份重签后侧载，不能直接安装。
- 同时提供匹配本标签的 `SwiftPeek-0.8.7-source.zip` 和 `SHA256SUMS.txt`；请核对下载文件的 SHA-256。
