# SwiftPeek 0.8.5 — macOS 界面刷新

版本 **0.8.5 (19)**。

## 原生窗口结构

- 主窗口改为系统侧栏加工具栏搜索，内容区首屏直接是第一排直播；分类下钻使用系统返回按钮。
- 搜索框移到工具栏，支持主播、房间号或直接粘贴链接；刷新按钮也放入工具栏。
- 偏好设置改为原生设置窗口，顶部标签由系统绘制。

## 内容与卡片

- 直播间卡片与 iOS 共用同一设计：封面即卡片，不加底板、描边和阴影，悬停时封面在圆角内轻微放大；观看历史的卡片显示观看时间。
- 关注的主播以头像、名字和当前标题一行排开，正在直播的带橙色细环和脉冲点。
- 内容直接落在窗口底色上，Liquid Glass 只用于系统侧栏、工具栏和播放控件；去掉多余的副标题和装饰文字。

## 播放与录像

- 直播间侧栏顶部是主播信息行：主播、热度、已播时长与关注放在一起，与 iOS 播放页一致。
- 录像和弹幕列表入口移到工具栏。
- 录像页与 iOS 使用相同结构：标题与元信息、分段选择、当前内容；只有当前章节使用品牌色。

## 下载与安装

- `SwiftPeek-0.8.5-macOS-universal.zip` 支持 **macOS 26+**，包含 **Apple Silicon arm64 与 Intel x86_64**。解压后将 `SwiftPeek.app` 拖入「应用程序」。
- 应用使用不包含个人身份的 **ad-hoc 签名**，未经 Developer ID 公证。核对来源和 SHA-256 后，可按系统提示在「系统设置 → 隐私与安全性」允许打开。
- 同时提供匹配本标签的 `SwiftPeek-0.8.5-source.zip` 和 `SHA256SUMS.txt`。
