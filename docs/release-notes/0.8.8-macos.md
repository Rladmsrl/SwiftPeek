# SwiftPeek 0.8.8 — 弹幕与直播重连修复

版本 **0.8.8 (22)**。本版修复 0.8.7 引入的弹幕频繁重连，并减少直播在网络波动时不必要的换线重连。弹幕与播放内核与 iOS 共用，两端同步修复。

## 弹幕

- 修复弹幕约每 45 秒断开并重连一次的问题。0.8.7 在每次心跳时额外发送 WebSocket 协议层 ping，斗鱼弹幕服务器收到后会立即断开连接；现已移除，改为以服务器回送的心跳判断连接是否存活。
- 连续两次心跳都没有任何回应才判定连接失效，偶尔丢一次回包不再触发重连。

## 直播播放

- 网络短暂波动时不再急于换线：连接静默超过 8 秒（原为 4 秒）才另开连接，避免新旧两条连接争抢带宽、随后频繁切换线路。
- 卡顿后等待缓冲攒够再续播的这段时间，不再被误判为断流而触发换线重连。
- 「已关注」按钮文字始终保持一行。

## 下载与安装

- `SwiftPeek-0.8.8-macOS-universal.zip` 支持 **macOS 26+**，包含 **Apple Silicon arm64 与 Intel x86_64**。解压后将 `SwiftPeek.app` 拖入「应用程序」。
- 应用使用不包含个人身份的 **ad-hoc 签名**，未经 Developer ID 公证。核对来源和 SHA-256 后，可按系统提示在「系统设置 → 隐私与安全性」允许打开。
- 同时提供匹配本标签的 `SwiftPeek-0.8.8-source.zip` 和 `SHA256SUMS.txt`。

## 验证范围

共享库 62 项测试与 11 组离线播放检查（含本次新增的回归用例）通过；Universal 双架构构建与包内隐私检查通过。弹幕修复用应用内同一份弹幕客户端连接真实斗鱼服务器对照验证：修复前约每 45 秒断开一次，修复后连续 3 分半钟未断开，热门房间 70 秒内收到 901 条弹幕。

本版未运行应用界面或试播；真实弱网下的直播换线仍需在实际环境中验收。Intel 架构为交叉编译，尚未在 Intel 设备或 macOS 26 真机上验证。
