# SwiftPeek 0.8.7 — 全面体检与稳定性修复

版本 **0.8.7 (21)**。本版来自一次覆盖播放内核、弹幕、录像、数据存储与 Mac 窗口的整体代码审查，没有新增大功能，集中修复审查中确认的问题。

## 直播播放

- 修正缓冲时长计算：音视频时间戳轻微交错时，缓冲时长可能被算成一个巨大的值，使起播与卡顿后的续播门槛失效，表现为「播一下、卡一下」。
- 后台换流（约每 4 分钟刷新一次直播地址）失败后不再三次即放弃：改为 1 → 2 → 4 → 8 → 15 秒退避持续重试，只有连续失败超过 60 秒且缓冲已经播空才提示失败。接口短暂抖动不再导致约 5 分钟后断流。
- 单个异常数据包（例如空的音视频包）不再结束整场播放：跳过该包，视频等待下一个关键帧；同一连接持续出错时换一条新连接。
- 声音不再长期领先画面：生成的音频时间与容器时间相差超过 50 ms 时重新对齐，包括无缝换流留下的小空档。
- 同一连接内视频时间戳突然倒退（推流端重连等）时重新对齐时间轴，不再冻结画面。
- 卡顿后的续播余量 4.5 秒、6 秒两档现在真正生效。
- 播放失败后释放音频会话；渲染器出错重置后等到关键帧再显示，避免花屏。
- 播放循环大幅减少空转唤醒，校验每帧时不再复制整帧数据，多窗口同时播放时更省电。

## 弹幕

- 断网后弹幕不再在约 25 秒后永久断开：改为不限次数重连（2 → 4 → 8 → 16 秒，之后每 30 秒），网络恢复时立即重连；超过两个心跳周期收不到数据即判定连接已失效。
- 弹幕连接提示与取流提示分开记录，弹幕恢复不会再清掉「取流失败」之类的提示。
- 弹幕连接关闭后可以重新建立，窗口重新出现时会自动恢复。

## 直播窗口

- 空格（播放 / 停止）和 M（静音）在整个窗口内都可用，不再要求鼠标停在画面上；新增 D 显示 / 隐藏弹幕。
- 播放时控制条 2.5 秒后自动隐藏，全屏时同时隐藏鼠标指针；静音时拖动音量条会自动取消静音。
- 窗口被完全遮挡或最小化时暂停弹幕绘制与接收（画中画、悬浮窗显示时除外），恢复可见后重新接收。
- 用别名或短房间号打开一个已经开着的直播间时，直接切到已有窗口，不再出现两个窗口同时播放、声音叠加。
- 修改任何设置（例如拖动弹幕字号）不再让每个窗口重建一套播放器。
- 悬浮窗不再随每批弹幕整体重绘。

## 应用与窗口

- ⌘N 不再打开空白的直播间窗口。
- 外部链接（`douyu://`、斗鱼网页链接）与关注文件统一交给主窗口处理，直播间窗口在最前时也不会被吞掉。
- 只剩一个最小化窗口时点 Dock 图标会恢复该窗口；Dock 菜单「显示主窗口」在任何情况下都可用。
- ⌘Q 退出时保存当前音量与录像进度。

## 关注、列表与数据

- 进入「关注」不再每次全量查询：最近查过的在 2 分钟内复用，查询改为最多同时 5 个，一个慢请求不再拖住后面全部；状态无变化时不重写关注文件。
- 状态未知的主播单独显示为「状态未知」，不再归入「未开播」。
- 后台刷新列表失败时保留已加载的页码，继续下滑仍能加载更多。
- 轮播房间的状态确认在快速滚动后也能完成，失败后下次出现会重试。
- 关注或历史文件读取失败时先备份为 `*.corrupt-<时间>.json`，跳过损坏条目、保留完好条目，不再被空列表覆盖。

## 录像

- 关闭录像窗口或退出时完整释放播放器与监听；画中画内弹幕隐藏时不再合成画面，大尺寸画面只缩放一次。
- 小窗弹幕暂停 / 继续时不再闪烁；跳转后第一批弹幕完整显示。

## 下载与安装

- `SwiftPeek-0.8.7-macOS-universal.zip` 支持 **macOS 26+**，包含 **Apple Silicon arm64 与 Intel x86_64**。解压后将 `SwiftPeek.app` 拖入「应用程序」。
- 应用使用不包含个人身份的 **ad-hoc 签名**，未经 Developer ID 公证。核对来源和 SHA-256 后，可按系统提示在「系统设置 → 隐私与安全性」允许打开。
- 同时提供匹配本标签的 `SwiftPeek-0.8.7-source.zip` 和 `SHA256SUMS.txt`。
