# SwiftPeek 0.8.8 — 弹幕与直播重连修复

版本 **0.8.8 (22)**，适用于 iPhone、iPhone Duo 和 iPad。本版修复 0.8.7 引入的弹幕频繁重连，减少直播在信号波动时不必要的换线重连，并调整全屏画面切换。

## 弹幕

- 修复弹幕约每 45 秒断开并重连一次、界面反复出现「与弹幕服务器断开，正在重连」的问题。0.8.7 在每次心跳时额外发送 WebSocket 协议层 ping，斗鱼弹幕服务器收到后会立即断开连接；现已移除，改为以服务器回送的心跳判断连接是否存活。
- 连续两次心跳都没有任何回应才判定连接失效，偶尔丢一次回包不再触发重连。

## 直播播放

- 信号短暂波动时不再急于换线：连接静默超过 8 秒（原为 4 秒）才另开连接，避免新旧两条连接争抢带宽、随后频繁切换线路。
- 卡顿后等待缓冲攒够再续播的这段时间，不再被误判为断流而触发换线重连。

## 全屏

- 全屏默认显示完整画面。右上角按钮切换的「填满屏幕」只对本次全屏生效，不再延续到下一次全屏，退出全屏后也始终显示完整画面。
- 窄侧栏中「已关注」按钮文字不再折行。

## 下载与安装

- **iOS / iPadOS 26+、arm64** 设备包，不适用于模拟器。
- `SwiftPeek-0.8.8-iOS-unsigned.ipa` 是**无签名 IPA**，不含维护者个人签名身份或 provisioning profile。需要使用自己的有效签名身份重签后侧载，不能直接安装。
- 同时提供匹配本标签的 `SwiftPeek-0.8.8-source.zip` 和 `SHA256SUMS.txt`；请核对下载文件的 SHA-256。

## 验证范围

共享库 62 项测试与 11 组离线播放检查（含本次新增的回归用例）通过；设备 Release 编译与包内隐私检查通过。弹幕修复用应用内同一份弹幕客户端连接真实斗鱼服务器对照验证：修复前约每 45 秒断开一次，修复后连续 3 分半钟未断开，热门房间 70 秒内收到 901 条弹幕。

本版未在真机上运行界面或试播；全屏显示效果、真实弱网下的直播换线，以及此公开无签名 IPA 重签后的安装与播放仍需在设备上验收。
