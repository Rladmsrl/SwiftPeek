# SwiftPeek 0.8.4 — macOS 直播状态修复

版本 **0.8.4 (18)**。

## 发现频道状态更准确

- 修复发现频道卡片和焦点推荐将轮播房间统一标成「直播中」的问题，现在按接口返回的信息显示「直播中」或「轮播」。
- 分类列表同步使用相同判断；缺失或未知状态不再默认显示直播。
- 状态直接来自列表接口，不增加逐房间查询，保留原有分页与浏览方式。

## 下载与安装

- `SwiftPeek-0.8.4-macOS-universal.zip` 支持 **macOS 26+**，包含 **Apple Silicon arm64 与 Intel x86_64**。解压后将 `SwiftPeek.app` 拖入「应用程序」。
- 应用使用不包含个人身份的 **ad-hoc 签名**，未经 Developer ID 公证。核对来源和 SHA-256 后，可按系统提示在「系统设置 → 隐私与安全性」允许打开。
- 同时提供匹配本标签的 `SwiftPeek-0.8.4-source.zip` 和 `SHA256SUMS.txt`。

## 验证范围

Universal 双架构构建与包内隐私检查通过，共享库 47 项测试通过；已用实际房间接口交叉核对轮播状态。

Intel 架构为交叉编译，尚未完成 Intel 设备或 macOS 26 真机的安装与播放验收。
