# SwiftPeek 0.8.9 — 播放稳定性、渲染性能与体验全面优化

版本 **0.8.9 (23)**。本版对共享网络/协议层、直播与录像播放内核、弹幕渲染与 macOS 界面交互进行了一轮全面排查与修复。

## 直播与录像播放

- 修复 `CMSampleBuffer` 块缓冲内存分配路径，改由 CoreMedia 通过 `kCFAllocatorDefault` 分配与托管，消除跨分配器释放风险；FLV 解复用改为零拷贝切片与安全 `startIndex` 索引。
- 修复推流端时间轴回跳时缓冲时长归零、以及 `append` 换流后 `lastQueuedEnd` 未同步导致的假卡顿；缓冲播放循环改用批量出队并支持确认下播后及时终止，网络切换时主动取消过期准备任务。
- 修复录像 `seek` / 起播定位在 `finished == false` 时卡死加载态或进度条停滞的问题，优化 `bufferedTime` 区间选择与 `ReplayVideoView` 图层切换。
- 修复录像窗口被最小化或切到其他桌面后仍持续绘制弹幕与滚屏的问题，并补齐窗口关闭时的列表刷新取消；macOS 画中画小窗在视频分辨率就绪后自动校正窗口纵横比。
- 录像弹幕回放修复批内乱序、为超长录像裁剪内存上界，并修复切换录像时热度曲线残留旧数据及进度条预览气泡边缘裁剪。

## 网络、签名与弹幕性能

- `DouyuSign` 引入预热 `JSContext` 复用池（隔离执行并淘汰异常上下文），减少进房与续流时重复解析加密脚本的开销。
- 修复靓号 / 字母别名房间号签名失败、`searchAnchors` 忽略服务端错误码、`HTTPClient` 误包装取消错误、`douyu.com/room/<id>` 链接解析以及弹幕文本含 `@=` 时被误判为嵌套 STT 而变空的问题。
- 弹幕 WebSocket 改用共享网络路径监控，支持 Wi-Fi 与其他网卡切换时即时重连；脱敏日志正则改为静态预编译。
- 弹幕光栅化缓存 `CTFont`、色彩空间与短文本图像，隐藏弹幕时立即清理活跃动画；屏蔽词在设置更新时预规范化，降低高频弹幕主线程开销。

## 列表、设置与界面

- `AppSettings` 拆分为细粒度可观察字段、`RoomStatusConfirmations` 与 `ReplayProgressStore` 按房间/录像独立观察，减少无关卡片与列表行的整屏重绘。
- `RemoteImageCache` 增加并发请求合并，`RemoteImage` 缓存命中后同步局部状态避免 `NSCache` 回收后永久空白；`RecommendStore` / `CategoryRoomsStore` / `ReplayListStore` 改由 store 持有分页任务且瞬时错误不锁死加载更多。
- 搜索页接入直播间与主播分页加载；分类页支持 `⌘R` 强制刷新；修复关注刷新被取消后误锁状态 120 秒与取消关注残留状态。
- 修复 macOS 直播分辨率角标千位逗号（改为 `1920 × 1080`）；设置页弹幕区域/速度补齐数值读数与统一范围，新增带确认提示的「恢复默认设置」。

## 下载与安装

- `SwiftPeek-0.8.9-macOS-universal.zip` 支持 **macOS 26+**，包含 **Apple Silicon arm64 与 Intel x86_64**。解压后将 `SwiftPeek.app` 拖入「应用程序」。
- 应用使用不包含个人身份的 **ad-hoc 签名**，未经 Developer ID 公证。核对来源和 SHA-256 后，可按系统提示在「系统设置 → 隐私与安全性」允许打开。
- 同时提供匹配本标签的 `SwiftPeek-0.8.9-source.zip` 和 `SHA256SUMS.txt`。

## 验证范围

共享库 64 项测试（13 个套件）与 11 组离线检查脚本（含本次新增回归用例）全部通过；Universal 双架构 Release 构建、去符号重签、解包审计与下载校验通过。
