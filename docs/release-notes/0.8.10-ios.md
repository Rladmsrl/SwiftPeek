# SwiftPeek 0.8.10 — 修复 iPhone Duo 展开内屏方向锁定与 iOS 0.8.9 启动崩溃

版本 **0.8.10 (24)**，适用于 iPhone、iPhone Duo 和 iPad。本次仅发布 iOS / iPadOS 安装包（macOS 仍停在 **0.8.9 (23)**，无改动）；本版包含 `0.8.9` 的全部播放、渲染性能与交互优化，并修复以下两项关键问题。

## 修复内容

- **修复 iOS 0.8.9 启动崩溃**：将 `SimpleLiveApp` 中主窗口与多画面全屏页的 `.appAppearance()` 移回 `.environment(settings)` 内层，解决此前因读取不到环境对象导致的启动即闪退问题。
- **修复 iPhone Duo 外屏全屏横屏后展开内屏无法物理横竖屏旋转（#1）**：
  - 按 `UIWindow` 维度通过 `UIHingeInteraction`（iOS 27.1+）监听铰链姿态；当外屏已发起编程横屏覆盖且铰链开始展开（开合角达到约 20° 或进入 `partiallyOpen` / `fullyOpen`）时，趁场景仍处于外屏模式主动请求 `.all` 释放方向覆盖，并清空进入全屏前记录的方向。
  - 已处于内屏展开态时，点击全屏 / 退出全屏仅切换铺满布局，不再发起必然返回 `UISceneErrorDomain code 101` 的 `requestGeometryUpdate`。
  - 修复原本已处于横屏时进出全屏仍写入方向覆盖的问题；收到 code 100/101 时清理对应状态并在折回外屏 / 回到 compact 模式时兜底释放；首次在合盖外屏非全屏态挂载时执行一次 `.all` 清理，用于自愈旧版本或异常退出遗留在 scene 中的方向偏好。直播间与录像共用此逻辑。

## 下载与安装

- **iOS / iPadOS 26+、arm64** 设备包，不适用于模拟器。
- `SwiftPeek-0.8.10-iOS-unsigned.ipa` 是**无签名 IPA**，不含维护者个人签名身份或 provisioning profile。需要使用自己的有效签名身份重签后侧载，不能直接安装。
- 同时提供匹配本标签的 `SwiftPeek-0.8.10-source.zip` 和 `SHA256SUMS.txt`；请核对下载文件的 SHA-256。

## 验证范围

- 离线检查：`PlayerOrientationCheck`（40 项方向状态机断言）、`PlaybackLayoutCheck`（179,669 项布局边界断言）全部通过。
- 模拟器回归：在 iPhone Duo（iOS 27.2）模拟器通过 `testDuoOuterFullscreenUnfoldAndRefold`，覆盖残留方向覆盖自愈、外屏全屏横屏、展开内屏退出全屏与折回外屏再次全屏/恢复竖屏流程。
- 发布打包：设备 arm64 Release 无签名构建、去符号、解包隐私审计与上传回验通过。

本版未在物理 iPhone Duo 真机上逐项实测物理重力旋转、音频中断与公开无签名 IPA 重签后的真机安装播放，这些项目仍需在真机上验收。
