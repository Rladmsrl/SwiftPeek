# SwiftPeek 0.8.4 — iOS 全屏返回与直播状态修复

版本 **0.8.4 (18)**，适用于 iPhone、iPhone Duo 和 iPad。

## 播放页全屏体验

- 直播和录像页点击「全屏」，直接进入横屏全屏。
- 退出全屏恢复进入前的方向和对应布局：竖屏进入就竖屏返回，横屏进入就保持原来的横屏方向。
- 保留播放器、弹幕面板和录像面板选择，支持连续进出全屏；Duo 布局继续按实际可用空间避开折痕。

## 直播状态更准确

- 修复发现 / 推荐及分类中轮播房间被当成直播的问题，卡片明确区分「直播中」和「轮播」。
- 缺失或未知状态不再默认显示为直播；直接使用列表接口已有信息，不增加逐房间查询。

## 下载与安装

- **iOS / iPadOS 26+、arm64** 设备包，不适用于模拟器。
- `SwiftPeek-0.8.4-iOS-unsigned.ipa` 是**无签名 IPA**，不含维护者个人签名身份或 provisioning profile。需要使用自己的有效签名身份重签后侧载，不能直接安装。
- 同时提供匹配本标签的 `SwiftPeek-0.8.4-source.zip` 和 `SHA256SUMS.txt`；请核对下载文件的 SHA-256。

共享库 47 项测试通过，已用实际房间接口交叉核对轮播状态。普通手机模拟器完成直播 / 录像连续进出全屏、竖屏返回、横屏进入与面板恢复检查；开发签名版本已安装并启动。
