# SwiftPeek 0.8.3 — iOS 多画面直播与三档弹幕

版本 **0.8.3 (17)**。本次更新 iOS / iPadOS，macOS 安装包仍为 0.8.1。

## 同时观看多个直播间

- 在播放器控制栏点「加看」，从历史、关注、搜索或房间链接添加直播间，最多同时观看四路。
- 支持双屏、四宫格、主次布局和单路放大，随横竖屏及 Duo 可用区域调整。
- 默认仅一路出声；可切换声音来源、单格静音、全部静音或锁定声音。各路可独立暂停、重试、切画质、换线路和移除。
- 进入多画面和返回单画面复用原播放会话；旋转、切布局和交换位置不会主动重建播放器。放大时暂停隐藏的无声房间，返回后恢复。

## 弹幕直接显示在画面上

- 提供「关闭 / 仅主画面 / 所有画面」三档，默认仅主画面，并记住选择；每格也能单独开关弹幕。
- 仅主画面沿用原有密度和速度，不增加频率限制。
- 所有画面模式降低每格密度，每路最多每秒新增三条，超量丢弃；低电量或明显发热时暂时只显示主画面弹幕。
- 移除多屏中的独立弹幕面板，将空间留给视频。

## 体验与稳定性

- 修复搜索和键盘展开时「添加」按钮不可见、已选房间挤占后续搜索结果的问题。
- 修复切换声音后返回原播放器意外静音，以及重载房间后丢失单格弹幕开关的问题。
- 停止被多画面覆盖的原页面重复绘制弹幕，改善多路播放时的资源管理和音频会话协调。
- 简化「关于」，保留应用名和版本。

## 下载与安装

- 支持 **iOS / iPadOS 26+、arm64**，适用于设备，不是模拟器安装包。
- 附件 `SwiftPeek-0.8.3-iOS-unsigned.ipa` 为**无签名 IPA**，不包含维护者签名身份或 provisioning profile；请使用自己的有效签名身份重签后侧载，不能直接安装。
- 同时提供与发布标签对应的 `SwiftPeek-0.8.3-source.zip` 和 `SHA256SUMS.txt`。下载后请核对 SHA-256。
