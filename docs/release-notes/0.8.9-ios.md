# SwiftPeek 0.8.9 — 播放稳定性、渲染性能与体验全面优化

版本 **0.8.9 (23)**，适用于 iPhone、iPhone Duo 和 iPad。本版对共享网络/协议层、直播与录像播放内核、画中画性能以及 iOS 界面交互进行了一轮全面排查与修复。

## 直播、录像与画中画

- 修复 `CMSampleBuffer` 块缓冲内存分配路径，改由 CoreMedia 通过 `kCFAllocatorDefault` 分配与托管；FLV 解复用改为零拷贝切片与安全 `startIndex` 索引。
- 修复推流端时间轴回跳时缓冲时长归零、`append` 换流后 `lastQueuedEnd` 未同步、网络切换未取消过期准备任务，以及确认下播后仍反复重试的问题；缓冲播放热循环改为批量出队。
- 新增 iOS 音频中断恢复、耳机/蓝牙音频输出断开及音频渲染器自动 flush 监听，自动重置音频节拍或停止外放。
- 修复录像 `seek` / 起播定位在 `finished == false` 时卡死加载态或进度条停滞、切后台未开自动画中画时音频被系统暂停、`ReplayVideoView` 图层切换与 `onPiPRestore` 缺失。
- 修复 `RoomView` 与 `MultiWatchView` 中 `PiPController` 闭包的强引用循环、多画面 `PiPController` 惰性创建与按钮可用态、直播画中画时钟同步与清理；优化画中画 `vImage` 缩放复用缓冲与 VideoToolbox 降采样解码。
- 录像弹幕回放修复批内乱序并限制超长录像内存上界，修复切换录像时热度曲线残留及进度条预览气泡边缘裁剪。

## 网络、签名与弹幕性能

- `DouyuSign` 引入预热 `JSContext` 复用池，减少进房与续流时的重复脚本解析开销；修复靓号 / 别名房间签名失败、`searchAnchors` 错误码漏检、`HTTPClient` 取消错误误包装与 `douyu.com/room/<id>` 链接解析。
- 修复弹幕正文含 `@=` 等特殊字符时被误判为嵌套 STT 而变空的问题；弹幕 WebSocket 改用共享网络监控并在 Wi-Fi / 蜂窝切换时立刻重连。
- 弹幕光栅化缓存 `CTFont`、色彩空间与短文本图像，隐藏弹幕时清理活跃动画；屏蔽词预规范化并忽略大小写去重。

## 列表、多看与交互

- 隔离根视图外观修饰器并将 `AppSettings` 拆分为细粒度可观察属性；`RoomStatusConfirmations` 与 `ReplayProgressStore` 按条目独立观察，`ResponsiveMediaGrid` 在非折叠屏系统上跳过逐卡几何监听，大幅减少无关重绘。
- `RemoteImageCache` 合并并发图片请求，`RemoteImage` 缓存命中后同步局部状态防止内存回收后空白；各列表分页改由 store 持有任务且瞬时失败不锁死加载更多。
- 搜索页支持直达直播间链接与分页加载；多看房间输入兼容深链与靓号链接；全屏手势拒绝起手横向拖动避免误调亮度/音量；设置页「清空观看记录与日志」和「清空关注」均加入二次确认。

## 下载与安装

- **iOS / iPadOS 26+、arm64** 设备包，不适用于模拟器。
- `SwiftPeek-0.8.9-iOS-unsigned.ipa` 是**无签名 IPA**，不含维护者个人签名身份或 provisioning profile。需要使用自己的有效签名身份重签后侧载，不能直接安装。
- 同时提供匹配本标签的 `SwiftPeek-0.8.9-source.zip` 和 `SHA256SUMS.txt`；请核对下载文件的 SHA-256。
